# UI & UX Design
- Controls should be co-located with the element they control — audio/subtitle/language controls belong inside the video player, not on a separate screen. Confidence: 0.9
- Prioritizes quick access and discoverability — controls should be immediately visible and accessible without requiring navigation to another screen. Confidence: 0.85
- Prefers fixed/anchored control bars (e.g., bottom-fixed) so controls remain accessible regardless of scroll or zoom state. Confidence: 0.8
- Controls should be contextually accessible — available where and when the user needs them (e.g., while zooming, the player controls should still be reachable). Confidence: 0.8
- Prefers Netflix/YouTube-style Continue Watching row that resumes the same source from saved timestamp with progress bar and remaining-time label. Confidence: 0.85
- Prefers persistent My List bookmark row for quick access to saved titles alongside Continue Watching. Confidence: 0.85
- Prefers hiding empty sections entirely rather than showing empty placeholders — e.g., My List row should only appear once it has data. Confidence: 0.85
